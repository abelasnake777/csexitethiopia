  • NET01

    Communication components and quality

    [Exam Focus]
    • Communication components
      • Data: raw representations
      • Information: interpreted data
      • Message; sender; receiver; medium; protocol
      • Source creates data
      • Transmitter: data → signal
      • Receiver reconstructs data
      • Distance: engineering factor, not sixth component
      👁 Full explanation
      Data are raw representations; information is data interpreted for a purpose. Communication requires a message, sender, receiver, medium and agreed protocol. A source creates data; a transmitter converts it to a signal; a receiver reconstructs data. Distance affects engineering but is not a sixth component.
    • Communication quality
      • Delivery: intended recipient
      • Accuracy: preserved content
      • Timeliness: deadline
      • Jitter: arrival-delay variation
      • Average delay can conceal disruptive jitter
      • Throughput: achieved transfer rate
      • Reliability: dependable operation
      • Security: unauthorized actions
      • Scalability: growth without unacceptable degradation
      👁 Full explanation
      Delivery means reaching the intended recipient; accuracy means preserving content; timeliness means meeting a deadline; jitter means variation in arrival delay. A call can have acceptable average delay yet sound broken because of jitter. Throughput measures achieved transfer rate, reliability measures dependable operation, and security concerns unauthorized actions. Scalability means accommodating growth without unacceptable service degradation.

  • NET02

    Network size, access and architecture

    • Network geographic scope
      • PAN: personal Bluetooth devices
      • LAN: building or campus
      • MAN: metropolitan region
      • WAN: distant regions
      • Device count alone insufficient
      • Internet: global network of networks
      • Internet as largest WAN example
      👁 Full explanation
      PAN connects personal devices, such as Bluetooth accessories. LAN covers a local building or campus; MAN spans a metropolitan region; WAN connects distant regions. Device count alone does not determine the category. The Internet is a global network of networks, commonly the largest example of a WAN.
    • Access scope and service roles
      • Intranet: organizational internal services
      • Extranet: approved outsiders
      • Access scope ≠ geographic size
      • Client requests; server supplies
      • Peers perform both roles
      • Dedicated servers can also be clients
      • DNS; backup; update dependencies
      • Ten-user cutoff: guideline only
      • Centralization: simpler administration, concentrated dependencies
      • Peer networks still require security
      👁 Full explanation
      An intranet serves an organization internally; an extranet exposes selected services to approved outsiders. Neither term alone specifies geographic size. A client requests a service; a server supplies it. Peer systems may perform both roles. Dedicated servers concentrate on service workloads but can still be clients of DNS, backup or update services. A ten-user cutoff is a teaching guideline, not a technical law. Centralization simplifies administration but creates dependencies; peer networks still need security.

    Protocols, standards and layers

    [Exam Focus]
    • Protocols and standards
      • Syntax: message structure
      • Semantics: field meanings
      • Timing: exchange schedule and rate
      • Standards enable interoperability
      • De facto: established use
      • De jure: formal approval
      • ISO: international standards
      • IEEE: 802.3 Ethernet; 802.11 Wi-Fi
      • ITU-T: telecommunications
      • ANSI: US standards coordination
      • EIA: interface standards
      • FCC: regulator
      👁 Full explanation
      Protocol syntax defines message structure, semantics defines field meanings, and timing defines when/how fast exchanges occur. A standard supports interoperability. De facto means established through use; de jure means formally approved. ISO develops international standards; IEEE develops LAN standards such as 802.3 and 802.11; ITU-T develops telecommunications standards. ANSI coordinates US standards, EIA is associated with interface standards, and FCC is a regulator.
    • Layer models
      • Reference model: responsibilities and interfaces
      • Model ≠ executable software
      • OSI: seven reference layers
      • TCP/IP: implemented suite, usually four layers
      • Five-layer model separates physical and link
      • State model before counting
      👁 Full explanation
      A reference model divides responsibilities and interfaces; it is not itself executable networking software. OSI is a seven-layer reference model; TCP/IP describes an implemented protocol suite, usually taught with four layers. A five-layer teaching model separates physical and link functions. State the model before counting layers.

  • NET04

    Signals, periods and bandwidth

    [Exam Focus]
    • Signal characteristics
      • Analog: continuous; digital: discrete symbols
      • Data type ≠ signal type
      • Digital bits modulate analog carriers
      • Sine wave: amplitude, frequency, phase
      • f: cycles/second
      • T=1/f
      • λ=v/f; propagation speed v
      • Phase: within-cycle displacement
      • Composite signals combine frequencies
      👁 Full explanation
      Analog signals vary continuously; digital signals use discrete symbol states. Data and signal types are separate: digital bits can modulate an analog carrier. A sine wave has amplitude, frequency and phase. Frequency f counts cycles/second, period T=1/f, and wavelength λ=v/f depends on propagation speed v. Phase specifies displacement within a cycle. Composite signals combine frequencies.
    • Bandwidth and carrier placement
      • Frequency bandwidth=highest−lowest; hertz
      • Low-pass includes zero frequency
      • Band-pass: nonzero frequency range
      • Baseband: no carrier shift
      • Passband: modulated carrier
      • Hz ≠ bit/s
      • 2 kHz → T=0.5 ms
      👁 Full explanation
      Frequency bandwidth is highest minus lowest frequency, measured in hertz. A low-pass channel includes zero frequency; a band-pass channel occupies a nonzero frequency range. Baseband sends the signal without shifting it to a carrier; passband transmission modulates a carrier. Do not confuse hertz with bit/s, even though both are informally called bandwidth. At 2 kHz, one period is 0.5 ms.

  • NET05

    Bit rate, baud and channel capacity

    [Exam Focus]
    • Bit rate versus baud
      • R: bits/second; bit interval=1/R
      • Baud: symbols/second, not voltage transitions
      • M states → log2(M) bits/symbol
      • R=baud×log2(M), before coding overhead
      • Manchester: extra transitions
      • Binary ≠ universally baud=bit rate
      👁 Full explanation
      Bit rate R is bits/second; a bit interval is 1/R. Baud is symbols/second, not necessarily the number of voltage transitions. With M equally encoded symbol states, each symbol can carry log2(M) bits; R=baud×log2(M), before coding overhead. Binary Manchester uses extra transitions, so binary does not universally mean baud equals bit rate.
    • Channel capacity bounds
      • Nyquist: ideal noiseless channel
      • R≤2B log2(M)
      • Shannon: Gaussian noise
      • C=B log2(1+S/N)
      • S/N: linear power ratio
      • SNR(dB)=10 log10(S/N)
      • Bandwidth; signal levels; noise
      • Distance affects attenuation, delay, achievable rate
      • Distance absent from simplified formulas
      👁 Full explanation
      For an ideal noiseless channel, Nyquist gives R≤2B log2(M). For Gaussian noise, Shannon gives C=B log2(1+S/N), with a linear power ratio; SNR(dB)=10 log10(S/N). Bandwidth, signal levels and noise appear explicitly. Distance affects attenuation, delay and often achievable rate, but is not a separate variable in these simplified capacity formulas.
    • Worked example Nyquist and Shannon example
      • B=3000 Hz; M=4
      • 2×3000×log2(4)=12,000 bit/s
      • S/N=15 → log2(16)=4
      • Shannon limit=12,000 bit/s
      • 15 dB ≠ linear ratio 15
      👁 Full explanationWorked example
      B=3000 Hz and M=4 give a 12,000 bit/s noiseless limit. If S/N=15, Shannon also gives 3000×log2(16)=12,000 bit/s. Do not insert 15 dB as a linear ratio.

  • NET06

    Delay, impairments and transmission modes

    [Exam Focus]
    • Delay components
      • Transmission delay=packet bits/link bit rate
      • Propagation delay=distance/signal speed
      • Processing delay; queueing delay
      • 1000 bytes at 10 Mbit/s
      • Serialization=0.8 ms
      • Higher rate leaves propagation unchanged
      👁 Full explanation
      Transmission delay is packet bits divided by link bit rate; propagation delay is distance divided by signal speed. Processing and queueing add delay. A 1000-byte packet takes 0.8 ms to serialize at 10 Mbit/s; increasing line rate does not reduce propagation time.
    • Signal impairments
      • Attenuation: reduced strength
      • Distortion: changed shape, unequal frequency delays
      • Noise: unwanted energy
      • Thermal noise: random thermal motion
      • Crosstalk: nearby-channel leakage
      • Impulse noise: short disturbance
      • Amplifiers amplify noise too
      • Digital repeaters regenerate decisions
      • Corrupted bits not always recoverable
      👁 Full explanation
      Attenuation reduces signal strength. Distortion changes shape, often because frequencies have different delays. Noise adds unwanted energy: thermal noise comes from random thermal motion, crosstalk leaks from nearby channels, and impulse noise is a short disturbance. Amplifiers amplify noise too; digital repeaters regenerate decisions but cannot reconstruct every corrupted bit.
    • Transmission modes
      • Simplex: one direction
      • Half duplex: alternating directions, walkie-talkie
      • Full duplex: simultaneous directions, telephone
      • Serial: sequential bits
      • Parallel: multiple conductors, skew risk
      • Asynchronous serial: character start/stop bits
      • Synchronous framing: ongoing clock recovery
      • Serial timing ≠ browser asynchronous requests
      👁 Full explanation
      Simplex is one way, half duplex alternates directions, and full duplex permits simultaneous sending/receiving. A walkie-talkie is half duplex; a telephone conversation uses full duplex. Serial sends sequential bits; parallel uses multiple conductors and may suffer skew. Character-oriented asynchronous serial adds start/stop bits; synchronous framing uses ongoing clock recovery. Neither is synonymous with browser asynchronous requests.

  • NET07

    Cables, wireless and connectors

    [Exam Focus]
    • Guided media
      • Twisted pairs reduce coupled interference
      • UTP: unshielded; STP: shielded
      • Coax: axial conductor and outer shield
      • Fiber: guided light; EMI resistance
      • Fiber: high capacity and long reach
      • Suitable optics and installation required
      • Specification determines speed, cost, reach
      • Fiber remains tappable
      👁 Full explanation
      Twisted pairs reduce coupled interference; UTP has no added shield and STP adds shielding. Coax has an inner conductor and outer shield sharing an axis. Fiber guides light and resists electromagnetic interference; it supports high capacity and long reach, but requires suitable optics and installation. Exact speed, cost and reach depend on the specification, not the material alone. Fiber can still be tapped.
    • Unguided media and Ethernet cables
      • Radio; microwave; infrared
      • Ground waves follow Earth
      • Sky waves: ionized-layer reflection
      • Line-of-sight requires visibility
      • Microwaves belong to radio spectrum
      • Infrared generally blocked by walls
      • Antenna determines directionality
      • Omnidirectional: broad azimuth, not uniform 3-D
      • Straight-through: unlike MDI/MDI-X roles
      • Crossover: like roles, PC–PC, switch–switch
      • Auto-MDI-X removes legacy cable constraint
      👁 Full explanation
      Radio, microwave and infrared are unguided media. Ground waves follow Earth, sky waves can reflect from ionized layers, and line-of-sight paths require suitable visibility. Microwaves are radio waves in the broader physical classification. Infrared generally does not penetrate walls. Directionality depends on antennas: omnidirectional means broad azimuth coverage, not equal radiation in every 3-D direction. Legacy Ethernet straight-through cables join unlike MDI/MDI-X roles; crossover joins like roles, such as PC–PC or switch–switch. Auto-MDI-X can remove that requirement.

  • NET08

    Topology and failure reasoning

    [Exam Focus]
    • Topology and link scope
      • Physical: link layout
      • Logical: communication/access relationships
      • Point-to-point: two endpoints
      • Multipoint: shared medium
      • Full mesh uses point-to-point links
      • Contradictory module mesh statement
      👁 Full explanation
      Physical topology describes link layout; logical topology describes communication/access relationships. Point-to-point links join two endpoints; multipoint links share a medium. A full mesh consists of point-to-point links.
    • Topology failure reasoning
      • Bus: shared backbone; unterminated-break disruption
      • Star: central device
      • Star edge failure: one endpoint
      • Star central failure: whole star
      • Ring: loop; single-break vulnerability
      • Protected dual rings differ
      • Token Ring uses token passing
      • Token access not inherent to rings
      • Tree: hierarchy; hybrid: combined arrangements
      👁 Full explanation
      Bus uses a shared backbone; an unterminated break can disrupt the segment. Star connects endpoints through a central device: one edge failure isolates that endpoint, whereas central failure affects the star. Ring forms a loop; basic single rings are vulnerable to a break, while protected dual rings differ. Token passing is associated with Token Ring but is an access method, not a necessary property of every ring. Tree is hierarchical; hybrid combines arrangements.
    • Full undirected mesh calculations
      • Links=n(n−1)/2
      • Interfaces/node=n−1
      • 50 nodes → 1225 links
      • Redundancy improves fault tolerance
      • Higher cable and interface cost
      👁 Full explanation
      A full undirected mesh of n nodes needs n(n-1)/2 links and n-1 interfaces per node. For 50 nodes: 50×49/2=1225 links. Redundant paths improve fault tolerance at greater cable and interface cost.

  • NET09

    NICs, repeaters and hubs

    [Exam Focus]
    • NIC and physical functions
      • NIC: computer network interface
      • NIC commonly implements physical and link
      • Physical interface ≠ exclusively layer 1
      • Connectors; signaling; voltage; timing
      • Physical coding and modulation
      • PHY–MAC interface: hardware signaling
      👁 Full explanation
      A NIC supplies a computer’s network interface and commonly implements both physical and link functions. Calling a NIC a physical interface does not mean all its functions are layer 1. Physical specifications include connectors, signaling, voltage, timing and physical coding/modulation; the PHY interface to MAC handles hardware signaling.
    • Repeaters, hubs and device roles
      • Repeater: layer-1 signal regeneration
      • No destination-address inspection
      • Active hub: multiport repeater
      • Signals repeated onto other ports
      • Half-duplex hub: shared collision domain
      • Passive hub: connector
      • No MAC learning or collision elimination
      • Network printer: endpoint consuming services
      • Routers; hubs; access points: intermediaries
      👁 Full explanation
      A repeater regenerates layer-1 signals without inspecting destination addresses. An active hub is a multiport repeater: it repeats incoming signals onto other ports, placing half-duplex endpoints in one collision domain. A passive hub is a connector. A hub neither learns MAC addresses nor eliminates collisions. An endpoint such as a network printer consumes services; routers, hubs and access points are intermediary devices.
    • Legacy IEEE 802.3 PHY architecture
      • AUI: attachment unit interface
      • MAU: medium attachment unit
      • MAC interfaces to PLS
      • PLS: Physical Signaling sublayer
      • Physical-layer signaling: PLS
      • Architecture-specific, not universal OSI terminology
      • Other PHY designs: RS; PCS; PMA
      • Reconciliation; coding; medium attachment
      👁 Full explanation
      In the legacy IEEE 802.3 architecture with an attachment unit interface (AUI) and medium attachment unit (MAU), the MAC interfaces to the Physical Signaling (PLS) sublayer. For this legacy MAC interface, the relevant sublayer is PLS. This name is architecture-specific: other PHY designs use reconciliation (RS), physical coding (PCS), physical medium attachment (PMA) and related sublayers. Do not present PLS as a universal OSI sublayer name.

  • NET10

    Bridges, switches and access points

    [Exam Focus]
    • Layer-2 bridges and switches
      • Learn source-MAC-to-port mappings
      • Look up destination MAC
      • Known unicast: destination port
      • Same incoming segment: filter
      • Unknown unicast or broadcast: VLAN flood
      • Switch need not select one port
      • Wireless AP: wireless–wired link bridge
      👁 Full explanation
      A bridge or ordinary Ethernet switch operates at layer 2. It learns source-MAC-to-port mappings, looks up the destination, forwards a known unicast to its port, filters it if the destination is on the incoming segment, and floods an unknown unicast or broadcast within its VLAN. A switch does not always send only to one destination port. Wireless access points normally bridge wireless and wired link-layer traffic.
    • Switch collision and broadcast boundaries
      • Separate collision domain per port
      • Full-duplex point-to-point Ethernet: no collisions
      • Full duplex: no CSMA/CD
      • Independent simultaneous conversations
      • Broadcasts remain within VLAN
      • Additional controls may filter broadcasts
      • Layer-3 switch also routes
      • Function overrides marketing name
      👁 Full explanation
      Each switch port separates collision domains; full-duplex point-to-point Ethernet has no collisions and does not use CSMA/CD. Switching permits independent conversations simultaneously. Broadcasts still reach the VLAN unless another control filters them. A layer-3 switch also routes, so device marketing names do not override the function being examined.

  • NET11

    Routers, gateways and traffic controls

    [Exam Focus]
    • Routers and gateways
      • IP forwarding: destination prefixes, next hops
      • Routers separate broadcast domains
      • Local link broadcasts normally stopped
      • Default gateway: usually router
      • Protocol gateway: application-format translation
      • Gateway ≠ inherently every OSI layer
      👁 Full explanation
      Routers forward IP packets between networks using destination prefixes and next hops. They separate broadcast domains and normally do not forward local link broadcasts. A default gateway is usually a router, while a protocol gateway can translate application formats; therefore a gateway is not inherently a device that implements every OSI layer.
    • Firewall, VPN and modem
      • Firewall: policy-based allow/reject/inspect
      • Firewall need not encrypt
      • VPN: Virtual Private Network
      • Logical private connection over another network
      • Secure VPN: tunnel authentication and encryption
      • Modem: outgoing modulation, incoming demodulation
      • Home router may combine distinct functions
      👁 Full explanation
      A firewall allows, rejects or inspects traffic under a security policy; it does not necessarily encrypt. A VPN, Virtual Private Network, provides a logical private connection over another network; a secure VPN authenticates/encrypts its tunnel. A modem modulates outgoing and demodulates incoming carrier signals. These functions may coexist in one home router but remain conceptually distinct.

  • NET13

    Link control, framing and error detection

    [Exam Focus]
    • Link control and framing
      • LLC: upper-protocol identification/multiplexing
      • LLC may provide link control
      • MAC: medium-dependent addressing/access, frame delivery
      • Network addressing: layer 3
      • Ethernet; PPP; HDLC: link protocols
      • Headers: addresses, control/type fields
      • Synchronization and framing depend on protocol
      👁 Full explanation
      Link-layer LLC identifies or multiplexes upper-layer protocols and may supply link control; MAC handles medium-dependent addressing/access and frame delivery. Network addressing belongs to layer 3. Ethernet, PPP and HDLC are link protocols. Frame headers may carry addresses and control/type fields; synchronization and exact framing depend on the protocol.
    • Error detection versus recovery
      • Redundancy detects, not necessarily corrects
      • Even parity: even total ones
      • 1011 → parity bit 1
      • Odd flips detected; even counts missed
      • CRC: polynomial bits, XOR-division remainder
      • Receiver repeats CRC division
      • Internet checksum: end-around carry, complemented sum
      • Burst: first–last corruption, unchanged interiors included
      • Recovery: retransmission or sufficient FEC redundancy
      👁 Full explanation
      Detection adds redundancy but does not guarantee correction. Even parity adds a bit so the total number of ones is even: 1011 needs parity 1. It detects every odd number of bit flips but misses even counts. CRC treats bits as a polynomial and appends the XOR-division remainder; the receiver repeats the division. Internet checksums add words with end-around carry and complement the sum. A burst spans from the first corrupted bit through the last, including unchanged interior bits. Retransmission or sufficient forward-error-correcting redundancy is needed for recovery.

  • NET14

    Access control and reliable-link procedures

    [Exam Focus]
    • Random access
      • ALOHA: opportunistic sending
      • CSMA: carrier sensing
      • Legacy half-duplex Ethernet: CSMA/CD
      • Collision→jam→stop→random backoff
      • Jam indicates collision, not clearance
      • Wi-Fi 802.11: CSMA/CA
      • Waiting/backoff and acknowledgments
      • Hidden terminals remain despite sensing
      👁 Full explanation
      Random access allows contention: ALOHA sends opportunistically; CSMA senses before sending. In legacy half-duplex Ethernet, CSMA/CD detects collision, sends a jam indication, stops, and retries after random backoff. The jam signals a collision, not its clearance. Wi-Fi 802.11 uses CSMA/CA with waiting/backoff and acknowledgments; sensing does not eliminate hidden-terminal collisions.
    • Controlled access and reliable links
      • Polling; reservation; token turns
      • Correct coordination avoids contention collisions
      • Channelization: frequency, time, code
      • Stop-and-wait: one frame, await ACK
      • Timeout retransmission; sequence-bit duplicate detection
      • Sliding window: multiple unacknowledged frames
      • Link reliability/flow control: hop-local
      • Transport reliability/flow control: end-to-end
      • Ethernet detects corruption without delivery guarantee
      👁 Full explanation
      Controlled access uses polling, reservations or a token to grant turns; correctly coordinated access avoids contention collisions. Channelization divides frequency, time or code resources. Stop-and-wait sends one frame and waits for ACK, retransmitting on timeout; sequence bits distinguish duplicates. Sliding windows permit multiple unacknowledged frames. Link reliability/flow control is hop-local; transport reliability/flow control is end-to-end. Ethernet detects corruption but does not itself guarantee reliable delivery.

  • NET15

    Line coding, modulation and sampling

    • Line coding
      • Digital bits → digital signal patterns
      • NRZ: no forced mid-bit return
      • Manchester: clocking mid-bit transition
      • Manchester bit convention must be specified
      • Differential Manchester: relative-state transitions
      • AMI: alternating successive-one polarities
      • Pseudoternary: alternating zero pulses
      • Block coding adds redundancy
      • Scrambling replaces problematic patterns
      • Scrambling need not increase bit count
      • Multilevel: 2B1Q; 8B6T
      • MLT-3: voltage-transition sequence
      👁 Full explanation
      Line coding maps digital bits to digital signal patterns. NRZ uses levels without a forced mid-bit return; Manchester supplies a mid-bit transition for clocking, with bit convention specified. Differential Manchester encodes using transitions relative to previous state. AMI alternates the polarity of successive ones; pseudoternary alternates zero pulses. Block coding adds code redundancy; scrambling replaces problematic patterns without necessarily increasing bit count. Multilevel schemes include 2B1Q and 8B6T; MLT-3 uses a sequence of voltage transitions.
    • Modulation and digitization
      • ASK: amplitude; FSK: frequency; PSK: phase
      • QAM: amplitude plus phase
      • AM/FM/PM carry analog data
      • PCM: sampling→quantization→encoding
      • Practical sampling: fs>2fmax
      • b bits → 2^b levels
      • Uncompressed rate=fs×b
      • PAM: pulse amplitude; PWM: pulse width
      • PAM/PWM alone ≠ binary PCM code
      👁 Full explanation
      ASK varies carrier amplitude, FSK frequency, PSK phase; QAM combines amplitude and phase. AM/FM/PM can carry analog data. PCM digitizes analog input by sampling, quantizing and encoding. TDM allocates time slots: synchronous TDM reserves recurrent slots even if an input is idle, while statistical TDM allocates according to demand and needs identification.
