A practical study routine

One topic.
Five useful steps.

Use the study note as your main learning resource, the questions for practice, and the outline for revision. Start practicing while you work through the note.

For each topic, follow this cycle:

  1. 1

    Study the note

    Understand the rule, assumptions, examples and exceptions.

  2. 2

    Close it and recall

    Use the outline’s bullets to explain the topic aloud before revealing explanations.

  3. 3

    Attempt related questions

    Keep answers hidden; explain why each option is correct or incorrect.

  4. 4

    Correct mistakes

    Return to the relevant section and record what you misunderstood.

  5. 5

    Revisit later

    Repeat difficult questions after a gap, then gradually attempt mixed, timed papers.

Recalling information and checking feedback supports longer-term learning better than repeatedly reading alone. Carnegie Mellon’s guidance ↗

You can set aside cover-to-cover module reading for now. Keep the modules available for targeted checks when something remains unclear, an explanation seems questionable, or answers conflict. Use another authoritative reference when the module does not cover that concept.

Mark a topic “reviewed” when you can explain and apply it from memory, not simply after reading it.
