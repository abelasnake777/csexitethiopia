Answer & Detailed Explanation

Study-guide references

DAA12 · Choose a design from structural conditions

DAA16 · Sorting choices and comparison costs

Correct answer: D — Heap sort

DAA16 explicitly classifies heap sort as outside standard divide and conquer: it builds a heap and repeatedly extracts its maximum. Quicksort partitions and recursively sorts ranges; merge sort recursively sorts halves; binary search recursively or iteratively reduces to a smaller half. Thus heap sort is the single exclusion among the listed algorithms.

Evidence in the complete study note

Divide and conquer solves smaller largely independent instances and combines results. DP reuses a defined set of subproblem states. Greedy commits to a feasible local choice only when a safety argument supports it. Backtracking grows/retracts candidates when constraints fail; branch and bound also rejects candidates whose best possible objective cannot beat an incumbent.DAA12
Heap sort builds a max-heap in Θ(n), then extracts/restores in O(log n) per item: O(n log n) total, Θ(1) auxiliary space, ordinarily unstable. It is not standard D&C. Merge sort offers stability/worst-case guarantees; quicksort’s practical advantage depends on implementation/workload.DAA16

Choice by choice

A · incorrect — Quicksort partitions its input and recursively sorts the resulting smaller ranges, a standard divide-and-conquer pattern.

B · incorrect — Binary search repeatedly reduces a sorted search interval to one half; the note treats this as divide-and-conquer.

C · incorrect — Merge sort divides into halves, sorts each recursively, and combines them by merging.

D · correct — Heap sort builds a heap and repeatedly restores it after extraction, rather than independently sorting and combining subinstances.

Answer & Detailed Explanation

Study-guide references

DAA28 · Floyd–Warshall, reachability and negative cycles

Correct answer: B — Θ(n³)

Floyd–Warshall considers each intermediate vertex k and updates every ordered pair i,j. The three independent n-sized loop ranges perform Θ(n³) constant-cost updates. The n² output table explains storage, not the time of this implementation. Other graph assumptions can support different algorithms, so this is the cost of the explicitly named method rather than a universal best-achievable APSP bound.

Evidence in the complete study note

For all-pairs distances initialize D[i, i]=0, D[i, j] to the minimum direct edge weight, and missing edges to∞. Preserve a negative self-loop by taking min(0, its weight). For k outermost, update D[i, j]=min(D[i, j], D[i, k]+D[k, j]); before phase k, intermediates are restricted to earlier vertices. Guard unreachable sums and numeric overflow.DAA28
Three loops give Θ(V³) time and Θ(V²) storage. A negative diagonal afterward identifies a negative cycle; pairs able to traverse it have no finite minimum walk distance. Warshall reachability replaces min/+ by OR/AND. Floyd’s cost is not a universal best-achievable bound for all APSP settings; sparse nonnegative graphs permit repeated Dijkstra and other models permit other methods.DAA28

DAA14 · Merge sort: invariant, trace and costs

Correct answer: A — Merge sort

DAA14 splits into halves, recursively sorts each, and merges the results, directly implementing divide and conquer. DAA24 · Dijkstra: relaxation and the nonnegative condition

Correct answer: A — Multistage DAG shortest paths using stored reverse-topological cost-to-go values

Multistage DAG paths can be solved by storing the best cost-to-go for each vertex and evaluating vertices in reverse topological order. Each value combines outgoing-edge costs with already solved successor values, which is dynamic programming. The specified Dijkstra implementation uses greedy finalization, merge sort uses independent halves, and uncached chess tree search does not reuse stored subproblem values as described.

Evidence in the complete study note

DP reuses a defined set of subproblem states. Greedy commits to a feasible local choice only when a safety argument supports it.DAA12

                                                                                                            Answer: Choose greedy when a local-choice safety proof exists and its lower overhead meets the task.

                                                                                                            DAA19 supports exchange arguments that insert the greedy choice into some optimum without worsening it.                                                                                                             Evidence in the complete study note

                                                                                                            A greedy algorithm repeatedly selects a locally attractive feasible option without later undoing it. Optimal substructure alone does not prove this safe. An exchange proof inserts the greedy choice into an optimum without worsening cost; recurse. MST cut proofs use this exchange.DAA19

                                                                                                              DAA26 · Memoization, tabulation and Fibonacci

                                                                                                              Answer: Naive recursion repeats states exponentially; DP computes n states once.

                                                                                                              DAA26 gives tight naive call growth Θ(φ^n), so O(2^n) is a valid loose upper bound rather than the exact rate. Memoization or tabulation needs Θ(n) unit-cost additions and can keep two rolling values for value-only output. Arbitrary-precision arithmetic grows with output bit length and is not truly constant cost per addition.

                                                                                                              Evidence in the complete study note

                                                                                                              Naive Fibonacci recomputes F(n−2) across branches: call count is Θ(φ^n), with O(2^n) a valid loose upper bound. F(0)=0, F(1)=1 and F(i)=F(i−1)+F(i−2) yield Θ(n) unit-cost additions with memoization/tabulation. Keeping only two recent values uses Θ(1) machine words; arbitrary-precision output needs growing bit storage. This naive overlapping recursion is not the independent-subproblem ideal of D&C.DAA26

                                                                                                                Answer: Θ(n² log n)

                                                                                                                DAA10 has a=4, b=2, so n^(log_b a)=n². The additive f(n)=n² matches that power, selecting the balanced second case. Its logarithmically many levels each contribute Θ(n²), including the appropriate base work, so the total is Θ(n² log n). The polynomial-gap regularity condition belongs to the larger-f third case and is unnecessary here.

                                                                                                                Evidence in the complete study note

                                                                                                                For T(n)=aT(n/b)+f(n), a≥1, b>1, let p=log_b a. Level i has a^i nodes of size n/b^i. Compare f with n^p: a polynomial gap below gives Θ(n^p); f=Θ(n^p) gives Θ(n^p log n); a polynomial gap above gives Θ(f(n)) if a f(n/b)≤c f(n) for fixed c<1. The third case needs this regularity condition.DAA10
