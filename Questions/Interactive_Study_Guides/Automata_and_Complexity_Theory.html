AUT01 · Symbols, alphabets, words and length

Correct answer: A — Length

Count symbols rather than distinct symbols: that count is the string’s length, |w|. Alphabet is the set from which symbols are drawn, not the count in a particular string.

Evidence in the complete study note

An alphabet Σ is a finite set of symbols. A word/string is a finite ordered sequence of symbols from Σ; a language is a set of words, L⊆Σ*. An empty word ε, also written λ, has length zero. The empty language ∅ contains no words; {ε} contains one.AUT01
Length counts occurrences, not distinct symbols: |caddba|=6, so |caddba|²=36.AUT01

AUT02 · Concatenation, powers and reversal

Correct answer: C — fghe

Language concatenation preserves order: each word of L₂ is followed by a word of L₁. The four products are ec, ed, fghc and fghd. Thus fghe is the unique nonmember: its ending e is not one of the words available from L₁. The lowercase transcription repair makes the symbols consistent with the declared languages.

Concatenation xy writes x followed by y: cddc·ababb=cddcababb; order generally matters. εx=xε=x. Define x⁰=ε and xⁿ as n copies for n≥1. Reverse xᴿ reads symbols backward: caddba reverses to abddac; (xy)ᴿ=yᴿxᴿ and (xᴿ)ᴿ=x.AUT02

AUT13 · Build expressions and convert representations

Correct answer: B — Strings with at least two 0's

Each starred factor denotes any binary string, including the empty string. The two unstarred zeros therefore require at least two zero occurrences, while permitting arbitrary symbols before, between and after them. Conversely, any word with at least two zeros can be split at two selected zero positions to fit the expression. AUT06 · DFA definition and acceptance

Correct answer: D — Q and Σ to Q

For a deterministic finite automaton, finite control receives the current state and input symbol and chooses the next state. Thus δ:Q×Σ→Q. A general NFA instead has a set of possible next states, so the stem tacitly uses the deterministic convention.

Evidence in the complete study note

A deterministic finite automaton (DFA) is M=(Q,Σ,δ,q₀,F), with finite nonempty Q, start q₀∈Q, accepting set F⊆Q and total δ:Q×Σ→Q. Exactly one next state is specified per state/symbol pair; this does not mean the whole machine has one transition. F may be empty, recognizing ∅.AUT06
Start at q₀ and consume the entire input. Accept iff the ending state is in F; visiting an accepting state earlier is insufficient. ε is accepted exactly when q₀∈F. A nonaccepting sink loops on every symbol and cannot reach acceptance; it still finishes after finite input. Finite automata have finite memory encoded by states, not no state or no ability to remember any history.AUT06

B · incorrect — The second input must be a symbol, not another state.

C · incorrect — Omits the current state and uses two input symbols.

D · correct — Correct deterministic domain and codomain.

AUT04 · Grammars generate; automata recognize

Answer & Detailed Explanation

Study-guide references

AUT04 · Grammars generate; automata recognize

Correct answer: C — When the languages represented by both grammars are the same

A grammar specifies its generated sentences. Equality of the generated sets, not equality of alphabets or overlap, is the criterion for semantic equivalence. For example {a} and {a,aa} have the same alphabet and a common string but different languages.

Evidence in the complete study note

Write G=(V,Σ,P,S): finite variables V, terminals Σ disjoint from V, productions P and start variable S∈V. A production replaces its left side by its right side. The language is L(G)={w∈Σ*:S⇒*w}. A recognizer processes a word and accepts exactly the language members. Grammars generate languages; automata recognize languages, not grammars.AUT04
Two grammars are equivalent when their generated languages are equal, regardless of rule counts or variable names. One common word, equal alphabets or one-way inclusion is insufficient.AUT04

Choice by choice

A · incorrect — One-way inclusion allows extra strings in the other language.

B · incorrect — Same terminal alphabet permits different sets of sentences.

C · correct — Equality of the full generated languages establishes equivalence.

D · incorrect — A single shared string establishes overlap only.

AUT14 · Regular grammars and closure constructions

Correct answer: C — The concatenation L1L2 is regular.

Regular languages are closed under concatenation, so any two regular languages have a regular concatenation. Reversal preserves regularity but need not preserve the original language. Union needs no exclusion of the empty word, and arbitrary closures need not coincide.

Evidence in the complete study note

Right-linear rules have form A→aB, A→a or permitted ε rules; left-linear rules put the single variable at the opposite end, A→Ba. Both consistent orientations generate REG; arbitrarily mixing them can generate nonregular languages, for example S→aA|ε, A→Sb generates aⁿbⁿ. A CFG rule A→aBA is legal but not regular-grammar form.AUT14
Regular languages are closed under union, concatenation, star, reversal, intersection, difference and complement.AUT14

AUT16 · CFG derivations, sentences and parse trees

Correct answer: C — Path of a vertex from the root

A derivation is a sequence of production applications beginning at S and ending at a terminal word. Under the specified graph model, each application is one directed edge, so the root-to-terminal-vertex path records the complete sequence. A root alone gives only the start; degree and an immediate parent give local information. This graph is not being treated as a parse tree.

Evidence in the complete study note

In a context-free grammar (CFG) each production has one variable on the left, A→α with α∈(V∪Σ)*. A complete parse tree has root S, internal variable nodes expanded by productions and terminal leaves, with ε leaves when that convention is used. Read the leaves left-to-right for the yielded word. The whole tree represents derivation structure; a path in a derivation graph is a different object.AUT16

AUT18 · Ambiguity and precedence

Correct answer: D — more than one parse tree

Ambiguity is witnessed by one terminal string having two distinct parse trees. It does not require every string to be ambiguous, and a string with no parse tree is simply not generated.

Evidence in the complete study note

A CFG is ambiguous when some word has two distinct parse trees, equivalently two different leftmost derivations. Different expansion orders that give the same tree do not prove ambiguity.AUT18
Separate precedence levels: E→E+T|T, T→T*F|F, F→id|(E). Multiplication binds inside T before addition at E, and left recursion encodes left association. Uniqueness follows by the top-level last operator split and induction. S→SS|ε is already ambiguous for ε. S→A|B is ambiguous if A→ab and B→abB|ε both produce ab. Ambiguous grammar and inherently ambiguous language differ: another grammar may remove ambiguity.AUT18

B · incorrect — No tree means failure to derive the string, not competing derivations.

C · incorrect — A partial tree is unfinished and does not witness two full derivations.

D · correct — Two or more full trees for the same string meet the definition.

            AUT39 · Known hierarchy and open separations

            Correct answer: B — P versus NP remains open.

            AUT34 explicitly says P=NP remains open, and AUT39 lists the separation among unresolved questions. Therefore neither equality nor inequality is proved in this source.             Evidence in the complete study note

            Complexity classes here contain decision languages.             AUT25 · Context-sensitive rules and linear bounded automata

            AUT24 · CFL pumping proof and copy versus mirror

            Correct answer: B — A linear bounded automaton.

            An LBA checks block order then repeatedly marks one a, one b and one c, rejecting unmatched symbols. The language is not context-free, ruling out a PDA and therefore finite automata too.

            Evidence in the complete study note

            A context-sensitive rule αAβ→αγβ replaces A in context, with γ nonempty. Equivalently, noncontracting grammar presentations preserve/increase total length, with the isolated ε exception. The condition is on the complete sides, not an unrelated comparison |β|≥|α|.AUT25
            A linear bounded automaton (LBA) is a TM with O(n) tape cells on length-n input; the standard CSL characterization uses nondeterministic LBAs. For aⁿbⁿcⁿ first verify a*b*c* order, repeatedly mark one unmarked a, b and c, and reject missing/excess symbols.AUT25
            Thus every CSL is decidable.AUT25

            For s=aᵖbᵖcᵖ, the window vxy cannot contain both an a and a c. Pumping affects at most two blocks and at least one count. Use i=0 or 2: the unaffected third block retains p while another count changes, or symbol order breaks. Hence aⁿbⁿcⁿ is not CFL.AUT24
