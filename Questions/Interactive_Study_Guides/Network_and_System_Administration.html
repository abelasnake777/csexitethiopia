Answer & Detailed Explanation

Study-guide references

NSA04 · DHCP exchange and lease lifecycle

NSA05 · DHCP deployment, fallback and diagnosis

Correct answers (select all): A, B — An IP leased by the DHCP for a host is permanent; DHCP assures connectivity ever users move from location to location

A dynamic DHCP lease lasts for a specified interval and must be renewed; it is not a permanent assignment. DHCP can automate address configuration after moving, but connectivity also depends on a reachable server or relay, a suitable scope and a working network. The server selects addresses from its configured pool. Thus the permanence and guaranteed-connectivity claims are false, while pool selection and automatic acquisition are true.

Evidence in the complete study note

Static assignments and DHCP can coexist; avoid address conflicts. DHCP lowers repetitive administration but availability/security depend on deployment and protection from rogue replies. It does not guarantee connectivity whenever a device changes location.NSA05

B · correct — DHCP alone cannot assure connectivity after every location change; server, relay and network conditions matter.

C · incorrect — A DHCP server manages an address scope/pool, supporting selection from a predetermined range.

D · incorrect — Automatic acquisition of an address and options is a supported DHCP function.

NSA03 · Address, prefix, gateway and loopback

NSA11 · Routing, NAT and port translation

Correct answer: D — Private IP address is used in the LAN

Private IPv4 addresses are not directly routed as public Internet destinations. A gateway can translate those source addresses, often using port bindings so several clients share a public address. This works together with valid routing and the external connection. A missing default gateway must be repaired separately, and public addressing or uncertainty about the current configuration is not by itself a reason to enable NAT.

Evidence in the complete study note

An IPv4 address is 32 bits; a CIDR prefix determines its network. Compute network=address AND mask; devices use a route/gateway for remote subnets. Private ranges are 10/8,172.16/12 and 192.168/16; private addresses are not directly Internet-routable. Neither IP alone nor a class label determines today’s subnet.NSA03
Routing selects a next hop using a destination prefix; NAT rewrites addresses. Many-to-one address-and-port translation (PAT/NAPT) maps internal flows to one public address using distinct port bindings. For example, two private client sockets can appear as public-address ports 40001 and 40002, with replies translated back to the correct clients.NSA11
NAT is often used when private IPv4 clients access public networks; it does not itself replace a gateway, route, firewall or authentication. One-to-one NAT and destination translation are other forms, so NAT does not always mean many hosts share one address. Public addressing inside a LAN does not automatically require NAT. Unsolicited inbound service access may require explicit mapping and filtering.NSA11
