Study-guide references

SEC18 · Public keys and hybrid protection

Correct answers (select all): A, B, D — Awgichew uses Meron's private key KPRIV-M to encrypt his plain text; Awgichew uses his KPUB-A to encrypt his plain text; Meron can decode the scrambled text using her KPUB-M

A cipher replaces each plaintext letter with the next letter in the alphabet, wrapping Z to A. Which is the most specific standard cipher classification of this operation?

Study-guide sections

SEC13 · Substitution, shift and affine ciphers

Answer & Detailed Explanation

Study-guide references

SEC13 · Substitution, shift and affine ciphers

Correct answer: D — Substitution

The operation changes each symbol's identity while leaving its position in the message unchanged. That is substitution, and using the next alphabet letter is a fixed Caesar shift. General text-conversion descriptions do not identify this specific cipher class. Transformation is especially broad and could include many cryptographic or noncryptographic changes. D is therefore the most precise classification, rather than a claim that ordinary language can never describe encryption using broader terms.

Evidence in the complete study note

Substitution replaces symbols; transposition changes their positions. A monoalphabetic substitution preserves one mapping throughout the message and leaks frequency patterns despite a large nominal key space. Classical ciphers are teaching devices, not modern data protection.SEC13
With A=0 through Z=25, Caesar encryption is C=(P+k) mod26 and decryption P=(C-k) mod26. A shift of 3 maps A→D and HELLO→KHOOR.SEC13

B · incorrect — Incorrect: translation does not identify the specific cipher class defined by replacing symbols while retaining positions.

C · incorrect — Incorrect: transformation is a broader description and does not distinguish substitution from other changes.

D · correct — Correct: replacing symbol identities while keeping their positions is substitution.

    SEC01 · CIA and the property actually harmed

    Answer: Confidentiality limits disclosure: copying a private credit-card database breaches it. Integrity preserves correctness: changing an account balance improperly breaches it. Availability provides timely usable service: crashing a server or starving resources breaches it.

        SEC18 · Public keys and hybrid protection

        SEC16 · Symmetric keys, AES and distribution

        Answer: Symmetric encryption shares a secret key and efficiently protects bulk data. Asymmetric encryption uses a recipient public/private pair: encrypt to the authenticated public key and decrypt with the private key.
